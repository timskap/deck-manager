ЗАЩИЩЁННЫЙ SSH

Используется ключ, созданный ранее для этого проекта.

Пароль используется только для входа и не сохраняется.

Первое подключение? Подготовка Steam Deck ＋

На Steam Deck перейдите в Desktop Mode, откройте Konsole и задайте пароль пользователя, если его ещё нет:

passwd

Затем включите SSH:

sudo systemctl enable --now sshd

Компьютер и Deck должны быть доступны друг другу по сети. IP можно посмотреть в настройках подключения Deck. Если SSH использует другой порт, укажите его в поиске.
