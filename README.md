# Deck Manager

Локальная панель для управления Steam Deck с компьютера по SSH и SFTP.

## Запуск

Установите Node.js 22 или новее. На компьютере выполните команды в каталоге `deck-manager`.

```sh
npm ci
npm start
```

Откройте **http://127.0.0.1:8787**. Для подключения к Deck нужны SSH по домашней
сети или VPN и Python 3 на устройстве. Чтобы выбрать другой порт, запустите
`DECK_MANAGER_PORT=8788 npm start`.

1. На Deck в Desktop Mode откройте Konsole. Если пароль пользователя ещё
   не задан, выполните `passwd`, затем `sudo systemctl enable --now sshd`.
2. В панели найдите SSH-серверы в выбранной локальной сети или укажите IP/имя
   Deck. Поиск проверяет SSH-баннер; имя Steam Deck подтверждается после входа.
   По умолчанию проверяются порты 22 и 2222. Для известного адреса можно
   указать свой список или диапазон, например `2200-2230` (до 128 портов).
   Поиск сети ограничен выбранным локальным /24 и максимум 8 портами.
3. Войдите пользователем `deck` по паролю, существующему ключу проекта
   или выбранному приватному SSH-ключу. При первом подключении сверьте
   отпечаток ключа сервера; на Deck: `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`.
   Изменившийся ключ требует повторного подтверждения.
4. **Файлы:** загрузка файлов перетаскиванием, выбор целой папки, создание
   папок, просмотр и скачивание через SFTP. Файлы передаются потоком,
   до 32 ГБ на файл; готовое имя появляется только после успешной передачи.
   Существующие файлы не перезаписываются. Для папок используется кнопка
   «Выбрать папку». Обычные места: `~/Downloads`, `~/Emulation`, `/run/media`.
5. **Темы и Decky:** палитры и настройки PSP XMB, восстановление Steam Home,
   установка PSP XMB с резервной копией и перезапуск Decky. Подготовка сборки
   описана в разделе «Установка PSP XMB» ниже. Установка и перезапуск
   запрашивают пароль sudo, если он необходим. Настройки обновлённого PSP XMB
   подхватываются каждые 3 секунды; старой версии нужен перезапуск Decky.
6. **CSS Loader:** установите его через магазин Decky. Нажмите «Настроить
   удалённое управление» и перезапустите Decky, либо включите «Enable
   Standalone Backend» в настройках CSS Loader на Deck. Менеджер обращается
   к штатному API на `127.0.0.1:35821` **внутри Deck, через SSH**. Доступны
   включение/отключение установленных тем с обработкой зависимостей и
   установка ZIP, содержащего один `theme.json`. ZIP ограничен 128 МБ,
   распаковка — 512 МБ/10 000 файлов; ссылки и выход за папку запрещены.
   Существующая папка темы не заменяется. ZIP остаётся в `~/.cache/deck-theme-*`.
7. **Команды:** отдельные SSH-команды со stdout, stderr и кодом завершения.
   Каждый запуск имеет собственную оболочку: используйте `cd … && команда`.
   Лимиты: 2 минуты и 2 МБ вывода. Интерактивные `top`, редакторы и запросы
   `sudo` запускайте через обычный `ssh -p ПОРТ deck@АДРЕС` в терминале.
8. **Экран** показывает меню Steam и запущенную игру. После входа откройте
   [раздел «Экран»](http://127.0.0.1:8787/#screen) и нажмите **Начать трансляцию**.
   Кнопка **На весь экран** разворачивает изображение. Звук и управление остаются
   на Deck. Кнопка **Остановить**, выход из раздела или скрытие вкладки завершают захват.
9. В [медиатеке](http://127.0.0.1:8787/#media) доступны скриншоты и сохранённые
   клипы учётных записей Steam на Deck, снимки из папок `~/Screenshots` и
   `Pictures/Screenshots`, а также видео из пользовательской папки `Videos`.
   Нажмите миниатюру, чтобы открыть оригинал или посмотреть запись с перемоткой.
   Клипы Steam воспроизводятся напрямую по SSH. Скриншоты и отдельные видеофайлы можно скачать.

В игровом режиме менеджер получает изображение Gamescope через PipeWire. В рабочем
столе X11 используется активный дисплей. GStreamer передаёт кадры размером
960 × 600 с частотой до 20 кадров/с по уже установленному SSH-соединению.

Панель слушает только loopback, проверяет Host/Origin и использует токен
для API. Пароли и выбранные приватные ключи не пишутся на диск; настройки
адреса и доверенные отпечатки находятся в `.cache/deck-manager/`, существующий
ключ проекта — в `.cache/pairing-private/`. После перезапуска панели нужно
войти снова. Не выставляйте порт панели в Интернет.

## Установка PSP XMB

Для кнопки **Установить PSP XMB** скачайте ZIP плагина из релиза и распакуйте
его на компьютере. Запустите менеджер с путём к папке, в которой лежит
`plugin.json`. [Релизы PSP XMB](https://github.com/timskap/psp-xmb/releases)

```sh
PSP_XMB_PACKAGE_DIR="/путь/к/распакованному/psp-xmb" npm start
```

Если репозитории лежат рядом, выполните `npm ci` и `npm run build` в каталоге
`psp-xmb`. Менеджер автоматически найдёт `../psp-xmb/release/psp-xmb`.
Файлы, команды, экран и медиатека работают при самостоятельной установке менеджера.

## Проверки

Выполните `npm test`. Для Python-тестов нужен Python 3 на компьютере. Тесты запускают временный SSH-сервер
на localhost, проверяют ключи, пароль, команды, лимиты и безопасную установку ZIP.
CSS Loader использует [официальный локальный API](https://github.com/DeckThemes/SDH-CssLoader/blob/main/css_server.py)
и [методы плагина](https://github.com/DeckThemes/SDH-CssLoader/blob/main/main.py).
